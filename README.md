# TREINÔ: Sua Jornada Fitness - etapa 2

Crie um web app fitness premium, moderno, responsivo e mobile-first chamado TREINÔ.

A proposta da marca é:

“Você pode não ter um personal do seu lado. Mas não precisa mais treinar sozinho.”

O TREINÔ deve parecer um aplicativo real de treino e acompanhamento, e não uma simples área de membros ou página de curso.

IDENTIDADE VISUAL

Use esta paleta:

Verde-limão elétrico principal: #C8FF3D

Grafite quase preto: #111315

Off-white: #F7F8F5

A identidade deve transmitir:

energia

movimento

evolução

tecnologia

proximidade

Evite aparência de academia hardcore ou bodybuilding.

Não usar excesso de vermelho.

O visual deve lembrar um app fitness premium contemporâneo, com bastante espaço negativo, cards bem trabalhados, tipografia forte e moderna, cantos arredondados, sombras discretas e microinterações.
